# DesktopJukebox3D
mc唱片机音乐播放器
此应用完全由AI生成，仍处于开发阶段（因为token不够了:)）目前只实现了唱片机和音符渲染还有UI如果有bug请大神多多指点（我是初中生，自学c++，代码可能有很多不足）
新建一个文件夹并将图片和DesktopJukebox3D.java拖入，复制路径,打开cmd然后输入cd (你的文件夹名），然后运行javac DesktopJukebox3D.java和java DesktopJukebox3D
接下来是操作提示：
1.鼠标左键旋转
2.鼠标右键拖动
3.鼠标中键弹出UI
