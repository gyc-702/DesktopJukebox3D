# DesktopJukebox3D
mc唱片机音乐播放器
此应用完全由AI生成，已开发完成，如果有bug请大神多多指点（我是初中生，自学c++，代码可能有很多不足）
支持的音乐格式：mp3 wav ogg
新建一个文件夹并将图片和DesktopJukebox3D.java拖入，复制路径,打开cmd然后输入cd (你的文件夹名），然后运行javac -cp "lib/*" DesktopJukebox3D.java和java -cp ".;lib/*" DesktopJukebox3D
接下来是操作提示：
1.鼠标左键旋转
2.鼠标右键拖动
3.鼠标中键弹出UI
4.退出自动保存位置、旋转方向、上次打开的音乐
唱片机使用的是Faithful 64x材质包的纹理
